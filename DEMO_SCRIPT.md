# Valmart : test à deux appareils et script de démo (5 minutes)

Adresse du site : `https://TON-SITE` (web) et `https://TON-SITE/m/` (mobile). Salles réelles : `https://TON-SITE/#/room`.

## A. Avant la démo (5 minutes, une seule fois)

Appareils : un téléphone (le host), un ordinateur (le viewer), idéalement un second téléphone (le viewer mobile).

1. Sur le téléphone : ouvre `…/#/room`, choisis **Solo, automatic**, **Create the room**, **Go live**, autorise caméra et micro. Garde l'écran allumé.
2. Sur l'ordinateur : tape le code dans **Join a live** (ou ouvre le lien **Viewers**), puis **Join the live**.
3. Contrôle : image et son arrivent, un message écrit d'un côté apparaît de l'autre, l'outil lancé sur le téléphone apparaît sur l'ordinateur.
4. Si tu es seul pour montrer : touche **Demo crowd: on** sur le téléphone du host. Une foule simulée répond aux outils (le chat et la vidéo restent réels).

## B. Le script (5 minutes)

| Min | Tu fais | Tu dis |
|---|---|---|
| 0:00 | Montre le site (page d'accueil, Discover) | « Des hôtes locaux filment en direct, les voyageurs choisissent où aller. » |
| 0:45 | Ouvre un live, mode **Cinema** sur l'ordinateur | « Pour regarder sans être dérangé : trois éléments seulement. » |
| 1:30 | Passe au **vrai live** : le téléphone filme, l'ordinateur regarde | « Ici, ce n'est plus une simulation : vraie caméra, vrai réseau. » |
| 2:00 | Écris dans le chat depuis l'ordinateur, réponds depuis le téléphone | « Le chat est réel. » |
| 2:30 | Sur le téléphone : **Launch** (le bouton unique) | « L'hôte appuie une seule fois. L'outil apparaît chez tous les viewers. » |
| 3:15 | Sur l'ordinateur : réponds, **Look here** (repère sur l'image) | « Le viewer influence le live : le résultat revient à l'hôte en direct, avec une voix de synthèse pour lui. » |
| 4:00 | Active **Demo: I am walking fast** | « Quand l'hôte marche vite, aucun outil ne le dérange. » |
| 4:30 | Montre le mode **Team** (régie + caméra) | « Pour un hôte professionnel : un téléphone filme, un ordinateur pilote. » |
| 5:00 | Conclusion | « Gratuit à tester, deux appareils suffisent. » |

## C. Si quelque chose casse

| Problème | Geste rapide |
|---|---|
| Image noire sur le téléphone | Écran allumé, page ouverte, **Pause** puis **Resume** |
| Un viewer est coupé | Un bouton de reconnexion apparaît : le toucher |
| Plus de connexion du tout | Quota gratuit LiveKit atteint (5 000 minutes par mois) : montre la version simulée (`/#/app`), qui marche sans réseau |
| Le son ne vient pas | Touche **Sound on** sur le viewer |

## D. À dire honnêtement aux investisseurs

- Les données (villes, prix, hôtes) sont des exemples. La vidéo, le son, le chat et les outils des salles réelles sont réels.
- Les vidéos de démonstration d'autres lives restent des clips ou des emplacements.
- Les salles réelles n'ont pas de modération (choix pour la démo).
